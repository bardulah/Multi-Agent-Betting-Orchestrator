# Data Directory

This directory contains runtime data generated by the betting system.

## Active Data Files

### Match Data
- **matches.json** - Today's scraped matches (created by scraper)
- **matches-tomorrow.json** - Tomorrow's scraped matches (date-specific file)
- **history.json** - Historical match data used for statistical analysis

### Results
- **results.json** - Latest analysis results with BET recommendations
- **opportunities.json** - Opportunity scoring results

## Archive

The `archive/` subdirectory contains:
- **matches-YYYY-MM-DD.json** - Old match data by date (for reference)

These are preserved for historical analysis but are not actively used.

## File Structure

Each match file contains:
```json
{
  "matches": [
    {
      "date": "2025-11-18",
      "sport": "football",
      "league": "Premier League",
      "homeTeam": "Team A",
      "awayTeam": "Team B",
      "odds": { ... },
      ...
    }
  ]
}
```

Results file contains:
```json
{
  "timestamp": "2025-11-18T17:21:00",
  "recommendations": [
    {
      "homeTeam": "Team A",
      "awayTeam": "Team B",
      "recommendation": "BET|SKIP|HOLD",
      "confidence": 0.87,
      "agents": { ... }
    }
  ]
}
```

## Generation

Files are created by:
- **matches.json** - `npm run scrape` (today) or `npm run scrape:future` (tomorrow)
- **results.json** - `python3 run.py` (analysis)
- **history.json** - Automatically maintained by the system

## Cleanup

Old test data is archived automatically. Keep only:
- Current matches files (today and tomorrow)
- Latest results.json
- history.json for training
